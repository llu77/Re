# أصول تصميم eyework v2 (للحفظ والاطّلاع)

هذا الفرع يحفظ ما أُنتج أثناء تصميم الإصدار الثاني ولم يصل `main` بعد، كما هو، ليبقى
في المستودع لا في حاوية جلسةٍ تُستردّ. لا يُقدَّم منه شيء للمستخدم، ولا يُدمج هذا الفرع
كما هو: حزم الخطة تأخذ منه ما تبنيه (الحزمة 2 تأخذ `v2/client` إلى `eyework/client`).

| المسار | ما فيه | حالته |
|---|---|---|
| `OWNER_BRIEF.md` | طلبات المالك حرفياً وما تقرّر لها | مرجع كل المواصفات |
| `registration_spec.md` + `registration_sql/` | التسجيل بلا رابط، الحجمان، الموافقة | **دُمج** في `main` (0008، الحزمة 1) |
| `ai_spec.md` + `ai_sql/` | المراجع في الخلفية والمساعد وبوابة النموذج | **دُمج** في `main` (0009، الحزمة 1) |
| `inventory_spec.md` + `inventory_sql/` | أمين المخزون: الفواتير والأصناف والمرتجع والمصاريف | مسودة؛ تُعاد على 0009 في الحزمة 3 |
| `support_spec.md` + `support_sql/` | الدعم الفني بالإنسان في الحلقة وقاعدة المعرفة | مسودة؛ تُعاد على 0010 في الحزمة 4 |
| `marketing_sql/` | التسويق: الخطط والقنوات والبنود والنتائج | مسودة بلا مواصفة؛ الحزمة 6 |
| `v2/client/` | العميل الجديد (React + Tailwind + shadcn + 21st.dev): 68 شاشة بحجمين على بياناتٍ ثابتة | عرضٌ تصميمي مقيس؛ يُوصل بالخادم في الحزمة 2 |
| `visual/client/` | المسار البصري الأول (موصول بالواجهة البرمجية، إطار 72px) | تجاوزه v2 |
| `client/` | أوّل نقلٍ لمكوّني 21st.dev | تجاوزه v2 |
| `fixtures/`, `harness/`, `registration_check/`, `registration_measure/` | بيانات العرض وأدوات القياس ونتائجه | أدوات |

البناء المحلي لعرض v2: `cd design/v2/client && npm ci && npm run build:demo` ثم افتح `dist-demo/demo.html`
(`?screen=` يختار الشاشة، و`?size=large` الحجم الكبير).
